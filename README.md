New Super Mario Bros. Wii: New Horizons (placeholder)

# **HOW TO INSTALL:**
1. Download [NSMBWer+ Vanilla Branch](https://github.com/Ryguy0777/NSMBWerPlus/tree/vanilla-compatible) (click on the "code" button and download ZIP) 
2. Download the New Horizons patch (click on the "code" button and download ZIP)
3. Extract the contents of the NSMBWer+ zip
4. copy the folders inside the New Horizons zip file ("Env", "NewerRes", "Object" etc.) and paste them in the "NSMBWer+" folder, the folder that's located inside of "NSMBWerPlus-vanilla-compatible/NSMBWer+" and that contains the game file folders ("BGs", "Font", "Layout" etc.). If it asks to overwrite files, do it.
5. Copy the NSMBWer+ folder (the one containing the game files) to .../Dolphin Emulator/Load/Riivolution/
6. Copy the NSMBWer+.xml file inside of the Riivolution folder to .../Dolphin Emulator/Load/Riivolution/riivolution
Done!
# **HOW TO PLAY:**
Open up Dolphin, right click on New Super Mario Bros. Wii, start with riivolution patch, and make sure NSMBWer+ is Enabled. Press "Start" and enjoy!
