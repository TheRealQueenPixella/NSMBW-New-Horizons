# **HOW TO INSTALL:**
1. Download the New Horizons patch (click on the "code" button and download ZIP)
2. Copy the downloaded folders and files to .../Dolphin Emulator/Load/Riivolution/NewHorizons
3. Copy the NewHorizons.xml file inside of the Riivolution folder to .../Dolphin Emulator/Load/Riivolution/riivolution
Done!
# **HOW TO PLAY:**
Open up Dolphin, right click on New Super Mario Bros. Wii, start with riivolution patch, and make sure NewHorizons is Enabled. Press "Start" and enjoy!
